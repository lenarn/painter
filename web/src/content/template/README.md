# Content templates

The real content files live one level up, in `web/src/content/`, and are **not
part of the repository** — they contain the site owner's personal data.

To start your own site, copy these files into `web/src/content/` and replace
the placeholder text with your own (keep the JSON structure — it is the
contract the site code relies on):

```
news.json  about.json  education.json  exhibitions.json  contacts.json
afisha.json
```

`afisha.json` starts as an empty array: it is the selection behind the
«Where to go» block on the home page. With no entries the block is simply
skipped; fill it through the admin panel's Afisha page (tick events or add
your own manually — the agent search there is optional).

`catalog.json` is not a template: it is generated by the importer
(`go run ./tools/catalogimport "your folders"` from the repository root).
`catalog.example.json` here shows what a filled record looks like.
